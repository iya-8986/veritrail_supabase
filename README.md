# veritrail_supabase
Code for the database of the VeriTrail project. 
Executed using the Supabase website. 
Composed of 4 files: 01_schema, 02_seed_data, 03_sample_data, 04_test_queries

01_schema - Defines the complete database structure, including tables, columns, primary keys, foreign keys, constraints, relationships, and other database rules.
02_seed_data - Populates the database with initial/master data required for the system to function, such as departments, roles, categories, statuses, and other predefined values.
03_sample_data - Inserts realistic sample records into the database for demonstration, development, and testing purposes.
04_test_queries - Contains SQL queries used to verify the database structure, relationships, data integrity, and functionality of the seeded/sample data.
